# Familystan

Landing page for [Familystan](https://familystan.com): a month-long family gathering at [Network School](https://ns.com) in Astana, Kazakhstan, in June 2027.

The site is a static page in `public/`, configured for [Cloudflare Workers static assets](https://developers.cloudflare.com/workers/static-assets/) via `wrangler.jsonc`.

## Local preview

```sh
npx wrangler dev
```
