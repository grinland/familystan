# Familystan

Landing page for [Familystan](https://familystan.com): a month-long family gathering at [Network School](https://ns.com) in Astana, Kazakhstan, in June 2027.

The site is a static page at the repo root, served by [GitHub Pages](https://docs.github.com/en/pages) at `familystan.com`.

## Local preview

Open `index.html` in a browser, or serve the repo root with any static file server:

```sh
python3 -m http.server
```
